# 已确认事项总清单（截至 2026-10-07）

编号便于逐条核对。"已确认"= 你明确同意过；"默认"= 我提出、你没反对、按默认执行；"待定"= 还没定。

## 一、目标与定位
1. 【已确认】目标是国内 2026 秋招"Agent / Harness 开发工程师"岗位的个人项目。工程岗，不是算法岗，不发论文，不复现论文。
2. 【已确认】项目要证明的是 harness 工程能力，评判者是同行面试官。
3. 【已确认】不做编码 agent，不做 DeepResearch、知识库、智能客服这类项目。
4. 【已确认】不做"给 Pi 补功能缺口"式的项目，不做回放/归因/评测基础设施为主线的项目。

## 二、底座
5. 【已确认】基于 Pi（earendil-works/pi，TypeScript）二开，不用 DeepSeek Harness。
6. 【已确认】"二开"的含义：不改 Pi 源码，把 Pi 当库，在它的接口上写我们的扩展和周边。
7. 【已确认】用到 Pi 的三块：pi-durable（可断点续跑的 agent 运行时，审核 agent 跑在它上面）、pi-ai（统一模型接口，判官注册成它的分类器）、pi-coding-agent（只做运营面命令行插件）。
8. 【已确认】pi-durable 是实验性模块，锁定版本 1.0.4；它不能运行 coding-agent 的日常扩展，审核 agent 用 durable 自己的扩展写法。

## 三、业务
9. 【已确认】业务是平台内容审核。真实流程三层：机审（规则 + 小模型 + 云 API，自动处理 95–99%，结论 通过/疑似/拦截）→ AI 审核员层（只处理疑似，输出 放行/处置/释放到人）→ 人审（每人每天 1,500–2,500 条，秒级时效，规则 20 大类 100 条，经常更新）→ 申诉复审。
10. 【已确认】我们的判官替代的是机审里的"小模型分类器 + 策略层"（规则当输入、概率可校准、一个模型管多类和多模态），不替代预处理、精确匹配、频控、去重。
11. 【已确认】Pi 上的 agent 是第二层"AI 审核员"：对疑似内容查证据、按规则出结论和理由，拿不准释放给人。
12. 【已确认】项目是两条腿：判官层做快判，agent 层做认知审核。

## 四、系统形态（"企业级"的定义）
13. 【已确认】接内容流：队列、按场景路由、并发上限、背压、对下游模型限流。
14. 【已确认】每条内容处理可恢复、幂等：进程被杀后零重复处置、零丢失。
15. 【已确认】规则版本化：热更新、影子回放、灰度、上线前回归门槛。
16. 【已确认】三层分流：判官快判 → agent → 人；每层有延迟和成本约束。
17. 【已确认】人在环：人审队列、人工结论回流、申诉重审、阈值按反馈重拟。
18. 【已确认】可观测：每条内容一条轨迹，仪表盘看吞吐、分流比例、放行率、释放率、p95、每千条成本、漏放误拦。
19. 【默认】架构拆两个进程：G（接入、预处理、快判、仪表盘、人审页、灰度 API，SQLite WAL）和 W（durable agent worker，每条疑似内容一个会话，处置经 outbox 写账本并加唯一约束）。
20. 【默认】人审工作台自建（一张页 + 三个 API），不接 Bluesky Ozone（它绑死 atproto 身份体系）。
21. 【默认】流量用公开数据集回放模拟，不接真实平台；账号历史、对话上下文、申诉、时序由程序合成，生成规则公开。

## 五、范围
22. 【已确认】第一版内容类型：短文本（评论、弹幕、昵称）、长文本（帖子）、图片/图文。不做视频、直播、音频。
23. 【已确认】第一版违规类别只做三类：不友好（辱骂/仇恨/歧视）、营销引流（广告、二维码、联系方式、黑产引流）、暴力（武器、血腥、惊悚）。
24. 【已确认】不做：色情、性暗示、涉政、未成年、宗教、博彩。原因：性相关容易让大模型出问题，先解决好解决的；涉政没有开源数据且敏感。
25. 【已确认】梗图数据集（ToxiCN_MM、Ex-ToxiCN-MM）不作为依赖，不用等申请。
26. 【已确认】不做的类别和数据局限在文档和评测卡里写清楚。

## 六、数据
27. 【已确认】文本数据：ChineseHarm-Bench（6,000 条，6 类，附规则知识库，CC BY-NC）、COLD（3.7 万条，Apache-2.0，可用于微调）、ToxiCN（1.2 万条，CC BY-NC-ND，只评测，直接从 GitHub 下）、zh-decision-bench（21 道审核题）。
28. 【已确认】图片数据：UnsafeBench（10,146 张，11 类，签数据协议）、VLGuard（MIT）、Roboflow 武器集与二维码集（CC BY 4.0）、把文本渲染成图、Open Images 抽难负例。
29. 【已确认】暴力类用的是英文和 AI 生成图，这点写进评测卡。
30. 【已确认】规则手册来源：ChineseHarm-Bench 的规则知识库 + 平台公开规范，整理成版本化规则，每条配五个测试样本（真违规、同词无害、引用、证据缺失、证据冲突）。
31. 【已确认】人审结论用数据集标注代替，没有真人审核员。
32. 【已确认】我不看任何数据集的样本内容；需要判定内容时交给 glm-5.3-flash；存疑样本只给你链接或行号；日志和界面默认脱敏。
