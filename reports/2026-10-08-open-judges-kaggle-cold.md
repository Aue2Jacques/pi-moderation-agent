# 开源判官 Laya、Kev 在 COLD 上的零样本测试记录（Kaggle T4，2026-10-08）

> **写法说明（2026-10-08 起统一）**：本文只记录做了什么、为什么这么做、测得的数字，以及考虑不够全面的地方。文中实验数字和看法均**仅供参考**（样本、设置、标注方式都有限），不作为结论；结论由审查方判断。日期按美国纽约时间（America/New_York）。

按 `docs/dev-plan-2026-10-08.md` 第 7 节，开源判官的测试已暂缓；这一轮是计划调整前就在运行的任务，结果只作记录。

## 做了什么

- 题目：`rules/prompts/jev-variants.yaml` 的选择题（abuse）和 7 道是非题（C_bool），与 Jev 题型对比报告用的是同一套题。
- 数据：COLD 开发集 6,431 条、测试集 5,323 条（Kaggle 任务自己从 GitHub 下载 COLD）。
- 模型：Laya multilingual（3.22 亿参数）；Kev（按 kev-4b fp16 → kev-4b bf16 → kev-0.8b fp32 依次尝试，实际用的是 **kev-4b fp16**，启动 96 秒）。单张 T4。
- 打分在 Kaggle 上做（`kaggle/score-cold/run.py`，通过 kernel_sources 读取前两个任务的输出），开发机只取日志。
- 组合模型：7 道是非题 → 逻辑回归，在开发集上 5 折交叉验证；测试集上用全部开发集训练的组合模型。

## 数字（仅供参考）

| | Laya | Kev（kev-4b fp16） |
|---|---|---|
| 可用条数：开发集 / 测试集 | 6,431 / 5,323 | **2,661 / 1,941**（错误 3,770 / 3,382） |
| 开发集 AUC：选择题"违规"概率 | 0.702 | 0.836 |
| 开发集 AUC：7 道是非题 → 逻辑回归 | 0.853 | 0.876 |
| 测试集 AUC：选择题 / 7 题组合 | 0.709 / 0.838 | 0.881 / 0.899 |
| 速度 | 约 39ms/条（批处理吞吐） | 约 1.0s/条（8 线程并发调本地服务的吞吐） |

## 不足（这些数字不能直接用的原因）

- **Kev 约六成请求出错**，可用条数只有约四成。缺失的不是随机的，可用的那部分可能偏容易或偏某类，所以 Kev 的 AUC 不能和 Laya、Jev 直接比。出错原因没有查（Kaggle 只取回了日志摘要）。
- **漏斗那几列（"交 agent 的比例"）没有列出**：打分脚本里的阈值算法和 `score-jev-variants.py` 一样，在同分多时会失效（两份外部审查指出，已复现），这些数字已知不可信，修好后再重算。
- COLD 测试集已经在之前的工作里用于挑阈值和分析漏放，这里的测试集数字属于"公开基准探索"，不是盲测。
- 速度是批处理吞吐，不是在线单条请求的 p95。
- Kaggle 任务从 `main` 分支拉题面，没有固定代码、数据和模型版本（计划 E4）。
- 只跑了一次；没有和 Jev 在同一批条目上对齐比较。
