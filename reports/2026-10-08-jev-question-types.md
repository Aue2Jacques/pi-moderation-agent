# Jev 三种题型对比（COLD 验证集 6,431 条，2026-10-08）

> **写法说明（2026-10-08 起统一）**：本文只记录做了什么、为什么这么做、测得的数字，以及考虑不够全面的地方。文中实验数字和看法均**仅供参考**（样本、设置、标注方式都有限），不作为结论；结论由审查方判断。日期按美国纽约时间（America/New_York）。

**问题**：Jev 的 System One 协议支持选择题（choice）、打分题（score）、是非题（bool）三种题型。我们一直只用选择题，而且没读它返回的把握度。换一种问法，能不能让快判更会区分好坏，从而少交一些给 agent？

**做法**：
- 同一份 COLD 验证集，三种问法各单独调用 Jev 一遍（并发 48，三种同时跑）。题目在 `rules/prompts/jev-variants.yaml`，按 v2 规则草案的"开放讨论"口径写。
- 是非题拆成 7 道，用 5 折交叉验证训练一个很小的逻辑回归，把 7 个概率合成一个分数。
- 统一对照 COLD 的二分类标签。脚本：`scripts/jev-variants.ts`、`scripts/score-jev-variants.py`。开发者没有看正文。

## 结果【实测】

| 问法 | AUC | 漏放 ≤15%、误拦 ≤5% 时交 agent | 漏放 ≤10%、误拦 ≤3% 时交 agent |
|---|---|---|---|
| 现在的做法（选择题，3 题一起问） | 0.786 | 48.8%（实际漏放 14.4%、误拦 5.0%） | 60.2%（9.2%、3.0%） |
| A 选择题单独问 | 0.783 | 49.3%（14.5%、5.0%） | 59.3%（9.6%、3.0%） |
| B 打分题（0–4 分，五档说明） | 0.754 | 54.2%（14.7%、5.0%） | 65.0%（9.8%、2.9%） |
| C 是非题 7 道 → 组合模型 | 0.833 | 42.2%（15.0%、5.0%） | 55.3%（10.0%、3.0%） |
| A+B+C 全部合起来（要调 3 次，参考上限） | 0.842 | 40.0%（15.0%、5.0%） | 53.4%（10.0%、3.0%） |

**更正（2026-10-08，dev plan §2.3）**：上表"交 agent"一列已用修正后的漏斗算法重算（`python/eval/funnel.py`：阈值取在实际漏放、误拦不超过目标的位置，括号里是实际值；n = 6,431，违规 3,211 / 正常 3,220）。原表按分位数取阈值、没有核对实际值，同分多时会失效（外部审查指出，合成数据复现：报告交 agent 0%、实际误拦 100%）。原表数字作废：现在的做法 48.5% / 59.8%，A 49.3% / 58.8%，B 53.9% / 64.8%，C 与 A+B+C 两行不变。

是非题单题的 AUC：
- threat 0.795、demean_group 0.774、stereotype 0.742、insult_person 0.704；
- humiliate_person 0.647、counter_bias 0.627；
- criticize_conduct 0.473，没有区分能力。

**选择题的把握度**：用它来区分判对和判错，AUC 只有 0.667。把握度 ≥ 0.95 的 2,628 条判对 81%；把握度 < 0.6 的 1,439 条判对 53%，接近乱猜。

**延迟和 token**：三种问法的 p50 都在 0.46 秒左右，p95 约 1.4 秒。平均 token（输入 / 输出）：选择题 481 / 40，打分题 580 / 17，是非题 7 道 796 / 131。

## 当时的看法（仅供参考）

- **最好的单次调用方案是"是非题 7 道 + 组合模型"**：AUC 从 0.786 提到 0.833，交 agent 的比例下降约 6–7 个百分点（按更正后的数字）。仍然只调一次 Jev，延迟不变，token 多一些。
- **打分题反而更差**，把握度只有一点用。
- **三种全用也只到 0.842**：按 COLD 的标准，Jev 能提供的区分信息大约就到这里。所以只调阈值和问法，交 agent 的比例在合理误差下降不到四成以下，离个位数很远。
- **原因有两种可能，现在分不开**：
  1. COLD 的标准比我们的规则严，而且标签本身有分歧（之前抽查，漏放里约三分之二是标准分歧）；
  2. Jev 在 COLD 这类隐晦偏见内容上确实不够强。

  要分开它们，需要两样东西：一是商用服务在同一份数据上的成绩，看 0.83 算高还是算低；二是按我们规则书标注的标准答案，看在我们自己的标准下表现如何。
